✨ The ARCANE Experience

🗂️ One Unified Gaming Library

Bring your gaming collection into a single, organized environment.

- Organize games across supported platforms.

- Integrate supported emulators with your games.

🔍 SmartScan — Your Library, Simplified

Spend less time organizing files and more time playing.

ARCANE's SmartScan system is designed to help discover supported games and organize them into the appropriate categories.

- Scan configured game directories.
- Identify supported game files.
- Organize detected games by platform.
- Reduce repetitive manual library management.
- Improve the workflow for growing game collections.

Detection results depend on supported formats, configured paths, and the installed software required to run each game.

🎨 SmartCover — Give Every Game Its Identity

A great gaming library deserves great artwork.

ARCANE's cover-management experience helps turn a basic list of games into a visually rich collection.

- Game cover and artwork support.
- Improved visual presentation of your collection.
- Artwork management for a more immersive library.
- Integration possibilities with supported artwork services.

🕹️ Emulator Integration

Classic gaming deserves a modern home.

ARCANE is designed to work with supported emulators, allowing users to organize and launch compatible retro games from one interface.

- Associate games with their appropriate emulators.
- Configure emulator executable paths.
- Manage game-specific launch settings.
- Organize supported console libraries.
- Extend your setup as emulator support evolves.

Your classics. Your collection. Your control.

🌌 BigMode — Enter the Big Screen

Gaming should feel immersive, not like managing a spreadsheet.

BigMode brings a cinematic, controller-oriented approach to navigating your gaming collection, making ARCANE suitable for a more console-like PC gaming experience.

- Full-screen gaming navigation.
- Controller-focused interaction.
- Visual game browsing.
- A dedicated experience designed around the big screen.
- A more immersive way to explore your library.

The goal: make your PC feel less like a desktop and more like a gaming console.

For users who prefer a traditional desktop environment, DesktopMode provides the familiar management experience.

Use it to organize your library, configure supported integrations, manage themes, and access ARCANE's available tools and settings.

Switch between managing your collection and enjoying an immersive gaming interface.

Theme Studio is designed to give users greater control over the appearance of ARCANE.

- Customize the visual experience.
- Work with supported theme presets.
- Create and manage themes.
- Import and export supported themes.
- Explore different visual styles through the theme collection.
- Personalize your gaming environment.

From clean minimalism to futuristic neon, your interface should feel like your own.

🏛️ Theme Gallery

Discover different visual identities for your gaming setup.

ARCANE's theme ecosystem is designed to make personalization an integral part of the experience, rather than an afterthought.

🎮 Controller & Gameplay Experience

ARCANE's controller-oriented features aim to improve navigation and provide a smoother transition between browsing and playing.

💻 Installation

Option 1 — Download a Release

1. Visit the official ARCANE repository.
2. Open the Releases section.
3. Select an available release.
4. Download the appropriate Windows package.
5. Run the installer and follow the instructions.

Official repository:
https://github.com/hadibader/Arcane

Releases:
https://github.com/hadibader/Arcane/releases

«Security notice: ARCANE may be distributed without a code-signing certificate. Windows SmartScreen or antivirus software may display a warning for an unsigned build. Always download releases from the official repository and verify the release contents before running them. Do not bypass warnings unless you trust and have verified the file.»

Option 2 — Build from Source

Requirements:

- Node.js and npm.
- Git.
- A compatible Windows development environment.
- Additional native build tools if required by native dependencies.

Clone the repository:

git clone https://github.com/hadibader/Arcane.git
cd Arcane

Install dependencies:

npm install

Start the development environment:

npm run dev

Build commands may vary by release. Check "package.json" for the exact scripts used by the current version to build and package ARCANE.
