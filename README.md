## 🚀 What's New in v0.8.0

Version **0.8.0** brings a massive visual and functional overhaul to the ARCANE ecosystem:

* ✨ **Brand-New User Interface:** A completely redesigned look and feel with modern layouts, smoother animations, and cleaner navigation across the entire launcher.
* 🛍️ **Built-in Free Game Store:** Browse, discover, and download free games directly inside ARCANE without leaving your hub.
* ⚡ **Upgraded Download Engine:** Faster, more reliable download management with better stability, progress tracking, and background handling.
* 🖥️ **Major Desktop & Fullscreen Mode Overhaul:** Radical improvements to both **Desktop Mode** and **Big Picture (Fullscreen) Mode** for seamless switching between mouse/keyboard and controller setups.
* 🛠️ **General Fixes & Under-the-Hood Improvements:** Better memory efficiency, squashed UI and emulator-linking bugs, and dozens of quality-of-life refinements.

## ✨ Core Features

* **Free Game Store** — Integrated storefront to discover and grab free-to-play and free titles effortlessly.
* **SmartScan** — Automatically indexes your configured directories for supported PC & emulator game files.
* **SmartCover** — Fetches high-resolution box art, banners, and metadata for a clean grid layout.
* **Emulator Linking** — Connects compatible retro titles directly to your configured emulators.
* **Theme Studio & Gallery** — Personalize colors, cards, backgrounds, and overall interface style.
* **Pocket Nova** — Explore and launch supported HTML games and companion mini-apps.
* **Torrent & Repack Workflows** — Enhanced download engine and automation tools in supported configurations.

## 📥 Installation & Setup

1. **Download** the official `ARCANE 0.8.0` installer from [GitHub Releases](https://github.com/hadibader/Arcane/releases/tag/Arcane0.8.0).
2. **Run** the setup file and follow the on-screen installation wizard.
3. **Configure** your game folders, ROM directories, and emulator paths inside Settings.

> ⚠️ **Important Note:**
> Always download releases directly from the official repository above. If Windows SmartScreen or your antivirus displays a warning for an unsigned executable, verify the source before proceeding.
