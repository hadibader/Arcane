## ✨ Core Features

* **Free Game Store** — Integrated storefront to discover and grab free-to-play and free titles effortlessly.
* **SmartScan** — Automatically indexes your configured directories for supported PC & emulator game files.
* **SmartCover** — Fetches high-resolution box art, banners, and metadata for a clean grid layout.
* **Emulator Linking** — Connects compatible retro titles directly to your configured emulators.
* **Theme Studio & Gallery** — Personalize colors, cards, backgrounds, and overall interface style.
* **Pocket Nova** — Explore and launch supported HTML games and companion mini-apps.
* **Torrent & Repack Workflows** — Advanced download engine and automation tools.

## 📥 Installation & Setup

1. **Download** the official `ARCANE 1.0.4` installer from [GitHub Releases](https://github.com/hadibader/Arcane/releases/tag/Arcane1.0.4).
2. **Run** the setup file and follow the on-screen installation wizard.
3. **Configure** your game folders, ROM directories, and emulator paths inside Settings.

> ⚠️ **Important Note:**
> Always download releases directly from the official repository above. If Windows SmartScreen or your antivirus displays a warning for an unsigned executable, verify the source before proceeding.
